# Брифы студии «Дела полетели»

Онлайн-брифы для клиентов студии. Сайт: https://pabloromanovps-arch.github.io/dela-brief/

| Бриф | Ссылка для клиента |
|---|---|
| Видеосъёмка | https://pabloromanovps-arch.github.io/dela-brief/#video |
| ИИ-видео | https://pabloromanovps-arch.github.io/dela-brief/#ai_video |
| Контент для экранов | https://pabloromanovps-arch.github.io/dela-brief/#screens |
| Фильм о компании | https://pabloromanovps-arch.github.io/dela-brief/#film |
| ИИ-агент | https://pabloromanovps-arch.github.io/dela-brief/#agent |

Ответы клиента остаются в его браузере: в конце он скачивает Word или копирует
текст и присылает студии. Страница собирается из закрытого репозитория студии
(`tools/brief/build_demo.py --standalone`) — здесь только готовый файл, правки
делаются там.
